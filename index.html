NFC / RFID Academy

Comprendre le NFC

Le NFC permet à deux appareils proches d'échanger de petites quantités d'informations.

Il existe différents types de tags et de cartes. Un navigateur web sur iPhone ne donne pas accès à toutes les fonctions NFC.

Cette version est un module pédagogique : elle ne lit pas et ne copie pas les badges d'accès.

À apprendre

• NFC et RFID : différences

• Tags compatibles NDEF

• Sécurité des communications sans contact

• Utilisation responsable de ses propres tags
